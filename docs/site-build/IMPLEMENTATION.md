## Scope and decisions

- Build all ten sections in src/site; preserve previous implementations as source checkpoints.
- Retain existing React / TypeScript / Vite stack and installed Three.js/R3F. Next.js is preferred, not mandatory in the brief; no server requirement justifies replacing the existing app architecture.
- Use native requestAnimationFrame scroll state, sticky positioning, SVG and CSS 3D for semantic diagrams. Use actual WebGL for the open-vessel hero installation. Do not layer gratuitous effects across the content.
- Use existing approved logo and supplied fonts; palette follows latest written architectural direction. The described architectural screenshot was not supplied with the latest message or present in the accessible attachments.
- Contact and booking integrations must disclose absent configuration and never report fictitious delivery. No real provider credentials, customer data or business contact details were supplied.
