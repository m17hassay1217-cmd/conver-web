One scene, one clock

Converdive's cinematic splash uses measured geometry and an absolute time to compute one scene state. The phrases, field, beam and DOM identity consume that same state; seeking or resizing reconstructs the frame without replaying event timers.

This internal architecture view applies Diagram Design's orthogonal connections, eight-node budget, accessible SVG and local horizontal scroller. It uses the established dark brand colors; system fonts keep this document self-contained. The diagram is documentation only and is not rendered inside the splash.
