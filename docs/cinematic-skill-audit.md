This table distinguishes substantive implementation from architecture decisions and incompatible workflows. Installing a package is not claimed as use.

## Conflict resolution

The supplied brief wins over generic theme, font, gradient and page-layout defaults. Hairline's rebuilding workflow and liquid-material application are not suitable here. R3F and ShaderGradient were evaluated as architecture options, not imported to inflate a skill count. Canvas 2D expresses the planar paths and beam while keeping the same measured coordinate system as DOM text.
