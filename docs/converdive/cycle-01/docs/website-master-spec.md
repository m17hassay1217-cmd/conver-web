# Converdive: authoritative website specification v0.1

## Goal and audience
A visually distinctive, UK-commercial-cleaning-focused, diagnostic-first website. Sell **a conversation**, not a generic AI package and not a guaranteed uplift. Convey Converdive's provisional offer: evaluate and selectively improve the enquiry → qualification → survey → quotation → approval → booked work continuum, preserving human oversight. Reuse a coherent motion language while preventing scroll fatigue.

## Storytelling rule
Every section answers one question and opens the next. Section-specific claims must be conditional unless independently substantiated. The site must never imply that a visitor *does* have a particular workflow defect, that all enquiries should convert, or that Converdive has proven customer results.

## Four selected, *provisional* scenario hypotheses
1. **Unsuitable enquiry effort**: Visible—time-consuming assessments produce few viable quotes. Mediator 1—enquiries reach inappropriate assessment/survey routes. Mediator 2—complexity, scope, geography, feasibility not assessed together. Proposed controllable condition—no dependable context-sensitive qualification/routing.
2. **Quotation rework / scope mismatch**: Visible—proposals repeatedly revised or incorrectly scoped. Mediator 1—quote scope fails to reflect latest agreed requirements. Mediator 2—survey, customer updates and changes aren't reconciled. Proposed controllable condition—no traceable requirements-to-proposal record/version process.
3. **Outstanding proposal stagnation**: Visible—interested prospects remain unconverted after proposals. Mediator 1—questions/revisions/approval dependencies remain unresolved. Mediator 2—next decision, owner or timing unclear. Proposed controllable condition—no dependable decision-readiness / next-action tracking.
4. **Missed existing-account expansion**: Visible—additional sites/services never progress to proposals. Mediator 1—new requests handled as isolated enquiries. Mediator 2—their relation to existing sites/agreements isn't recognized. Proposed controllable condition—no reliable account/site/opportunity linking.

These chains illustrate possible mechanisms; a real company may have alternate explanations. Automated assistants should only be shown supporting classification, summarization, record linkage and routing; pricing, feasibility, legal commitments and sensitive commercial approvals remain human-controlled.

## Content exclusions
- No guaranteed increase in bookings, revenue, profit, response speed or uptime.
- No fictional case study, review, customer logo, UK statistical claim, return-on-investment percentage or fabricated monitoring score.
- No prospect credential collection, account creation or contact information assumptions.
- Avoid overwhelming users with six-step scroll reveal where a three-stage summary suffices.

## Site success / first release
Main navigation works, all sections readable without motion, primary interactions usable on desktop and mobile, contact routes really function after integration, calculator transparent and deterministic, visual performance acceptable on mid-range hardware.
