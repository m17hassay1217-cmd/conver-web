# 18 — My Top Five Techniques for Web Animation
**Stack:** GSAP ScrollTrigger/SplitText, Framer Motion `useScroll`/`useInView`/`useTransform`, Lenis or Locomotive Scroll, CSS `position: sticky`, Intersection Observer, SplitType, JavaScript `requestAnimationFrame`, Canvas/WebGL shaders.
1. **Scroll tracking:** convert section scroll progress (typically 0–1) into animation values using GSAP ScrollTrigger or Framer Motion useScroll.
2. **Smooth the input:** prevent mouse-wheel stepping from making scroll-tied animation jerky using Lenis/Locomotive.
3. **Viewport entry:** trigger reveals when elements enter view; use Intersection Observer or wrapper hooks such as ScrollTrigger/useInView.
4. **Sticky composition:** pin visual layers using native CSS `position: sticky`, then combine it creatively with other scroll movement.
5. **Easing:** tune motion curves to achieve restrained, rapid or elastic character rather than default linear-feeling motion.
6. **Text splitting:** split paragraphs into lines/words/characters (GSAP SplitText or SplitType), animate units separately; check accessibility and resizes.
7. **Bonus — mapping:** remap input ranges (scroll, mouse pixels) into transform/opacity/coordinates via map/useTransform.
8. **Bonus — interpolation:** use `lerp` within requestAnimationFrame to smooth cursor, canvas, color and shape changes.
9. **Bonus — shaders:** use vertex/fragment shaders in WebGL for experimental deformation/material effects when justified.
**Scope:** A technique catalogue with examples, not a chronological build/deployment of one website.
