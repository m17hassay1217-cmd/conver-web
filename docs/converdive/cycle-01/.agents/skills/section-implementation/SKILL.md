# Section implementation skill
1. Read master spec, section spec, design tokens and adjacent section start/end states.
2. Explain the information hierarchy and fallback before coding.
3. Build semantic HTML/React DOM and working controls **without** effects.
4. Implement one visually dominant animation. Defer secondary decorations.
5. Run local test, screenshot desktop/mobile and check reduced motion.
6. Update a QA log; avoid touching already verified unrelated sections.
